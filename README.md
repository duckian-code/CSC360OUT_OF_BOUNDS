# CSC360OUT_OF_BOUNDS

CSC360OUT_OF_BOUNDS is a backrooms-inspired liminal dungeon crawler.

The user must avoid a multitude of terrifying warped creatures and attempt to find an exit to this endless maze.

## Structure

I plan on having an MVC format separating responsibilities in the application. Application logic will be appropriately separated between these with a simple JSON DAL.

## Future implementation

Potentially OpenAI integration for generating warped enemies for the player to avoid as well as dynamic floors/themes.
